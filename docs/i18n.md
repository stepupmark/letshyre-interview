# Internationalization

19 locales (`ar bn de en es fr hi id it ja kn ko ml nl pt ru ta te ur`) × 4 namespaces (`common`, `errors`, `interview`, `questions`), under `src/i18n/locales/<lang>/<ns>.json`.

## How a language is chosen

`src/i18n/resolveInitialLanguage.js` runs synchronously when `src/i18n/index.js` loads, before React renders:

1. `?lang=` on the URL. The desktop app attaches it on every launch, so it wins.
2. `sessionStorage.locale`, written by the desktop app on `dom-ready`. Best effort: it can land after this runs.
3. The site's own `sessionStorage.interview_language` from an earlier pick.
4. English.

The URL and app values count only if they are in `LANGUAGE_CODES` (`src/i18n/languages.js`). The result is stored under `interview_language`. The chosen language and English are loaded up front; others load on demand (`loadLanguage`).

`src/i18n/languages.js` also sets `dir` on the document (RTL for `ar` and `ur`) and lazy-loads the Noto font a script needs, so no candidate downloads every script's font.

## Rules

- English is the fallback; missing keys in any other locale degrade to English, never to a raw key.
- **All user-facing copy must be an i18n key.** Passing a literal string as a prop silently defeats the fallback: violation and termination copy resolve keys _inside_ the component, not at the call site.
- RTL (`ar`, `ur`) is handled with logical CSS properties (`ms-`/`me-`/`start`/`end`).
- Question and answer content comes from the backend and is not translated client-side.
- Placeholders are `{{name}}`. A translation must keep every placeholder the English string has.

## Changing a string

1. Change `src/i18n/locales/en/<ns>.json`.
2. Change the same key in the other 18 locales. `src/i18n/locales.test.js` fails if any locale is missing a key English has, or drops a placeholder.
3. A new key under `violations.electron.<key>` (desktop app violations) also needs its entry in `BY_KEY` in `src/lib/electronViolations.js`.

Raw `violations.…` or `termination.…` text on screen means a key is missing from `en/interview.json`.
